## Hi, I'm Fatema Tamanna

I'm a freelance AI engineer and ML/DL researcher. My research is on deep learning for time series and sequential data: hybrid forecasting models, and how sequence models behave and can be updated when their data changes over time. I also build AI agents and LLM applications that run in production.

### Research

- **Hybrid Deep Learning Approach for Load Profile Prediction**, STI 2024. BiLSTM/BiGRU/TCN with self-attention and an XGBoost meta-learner for smart-grid load forecasting. [Paper](https://easychair.org/publications/preprint/v2TS) · [Code](https://github.com/empresst/STI)
- **Enhancing Prediction Accuracy using Ensemble Deep Learning Methods on Time Series Data**, ICISET 2024. [Paper](https://ieeexplore.ieee.org/abstract/document/10939673) · [Code](https://github.com/empresst/ICISET)
- **Audit Before You Update**: recording artifacts and the limits of bounded model updates in MIMIC-IV ICU prediction. Preprint and code: [DataAudit](https://github.com/empresst/DataAudit)
  - Companion study on explanation stability when part of the model is frozen: [bounded_update](https://github.com/empresst/bounded_update)
